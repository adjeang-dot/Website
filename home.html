Ini adalah halaman utama. Kamu berhasil masuk karena data kamu tersimpan di localStorage browser.

Database Lokal - Semua Akun Terdaftar

Data ini disimpan di localStorage['fieldnote_users'] di browser kamu. Buka DevTools > Application > Local Storage untuk melihatnya.

Cara kerja penyimpanan:
1. Saat daftar: data masuk ke fieldnote_users (array)
2. Saat login: dicocokkan email & password dari array itu
3. Jika cocok: data user aktif disimpan di fieldnote_session
4. home.html cek session, kalau tidak ada → tendang ke login
